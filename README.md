# Trace Frontend - Modern Workout Tracker

The frontend of Trace is a visually stunning React 19 application built with a focus on user experience and performance. It features a modern "glassmorphism" aesthetic and interactive components for seamless workout management.

## ✨ Key Features

- **📅 Daily Focus Dashboard**: Real-time tracking of sets, reps, and workout progress.
- **🏗️ Multi-step Routine Builder**: A sophisticated wizard to create custom training plans.
- **🎨 Glassmorphic UI**: Premium look using Tailwind CSS and custom animations.
- **🛡️ Secure Auth Flow**: Integrated with backend for OTP verification and JWT session management.

## 🚀 Tech Stack

- **React 19**: Modern component-based UI.
- **Vite**: Fast development and build tool.
- **Tailwind CSS**: Utility-first styling with glassmorphism extensions.
- **Lucide React**: Vector icons.
- **Axios**: HTTP client with automated token handling.

## 🛠️ Setup Instructions

### 1. Prerequisites
- Node.js (v18+)

### 2. Installation
```bash
npm install
```

### 3. Configuration
Ensure the backend is running at `http://localhost:3000`. You can modify the API URL in `src/config/axios.js` or via the proxy setting in `vite.config.js`.

### 4. Development
```bash
npm run dev
```
The application will be available at `http://localhost:5173`.
